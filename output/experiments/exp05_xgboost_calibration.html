Findings
Calibration fix: Replacing residual bootstrap with quantile regression brings 80% coverage from 3.9% to 53.3% — a gain of 49.5 percentage points. The root cause of the original failure was XGBoost overfitting the training data: in-sample residuals were near zero, so bootstrapped intervals collapsed to near-point-predictions.

How quantile regression fixes this: Instead of adding noise from training errors, the model learns the conditional quantile function directly — i.e., how wide the prediction interval should be given the current covariate values. With 25 quantile levels (0.025 to 0.975), samples are drawn by uniform interpolation across the predicted distribution, properly capturing covariate-dependent uncertainty.

Best config: n_estimators=100, max_depth=4, learning_rate=0.05 — saved to exp05_best_config.json for use in Experiment 06 (improved ensemble).
